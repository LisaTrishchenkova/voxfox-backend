## API Documentation

Available in **dev** and **staging** environments only. Not exposed in production.

| UI      | Path        | Description                               |
| ------- | ----------- | ----------------------------------------- |
| Scalar  | `/scalar`   | Modern interactive docs with code samples |
| ReDoc   | `/api-docs` | Clean reference documentation             |
| Swagger | `/swagger`  | Interactive try-it-out UI                 |

> ⚠️ Documentation endpoints are disabled in production to limit information disclosure.
